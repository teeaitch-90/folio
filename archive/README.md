# Archive

Everything here is reference only. Nothing in this folder is served from the site root.

## v1-original/
The site as it was live before the 2026 redesign (cream background, Alexandria/Inter, purple brand). Contains index/Home, About, AtlassianTeams, CommBank, Macquarie, Westpac and gate.js. Asset paths were rewritten to `../../` so the pages still open from this folder.

## v2-dia-working-copies/
The redesign pages as they were authored in Claude Design (HomeDia, AboutDia, AtlassianDia, MacquarieDia, CommBankDia, WestpacDia). Their links point at each other by the Dia names. The live versions are the same pages with links rewritten to the production filenames.

## Redesign summary (v2, Oct 2026)
- Light, Dia/Arc-inspired style: off-white background, Geist, frosted glass panels, soft colour glows, reveal-on-scroll animation.
- Home: hero, tabbed showcase carousel (Atlassian first), work cards in matching pastel colours, About statement with Frame / Design / Build / Ship / Monitor row, "Where I've worked" logo strip, contact card.
- All four case studies rebuilt with animated pieces from the original designs. Hero labels use real company logos.
- Home has three Tweaks props: motion, glow, entrance.
- Logo: black rounded square mark in the nav.

## Restoring v1
Safest route: in GitHub Desktop, check out the `v1-archive` branch (created before the v2 push), or copy files from `archive/v1-original/` to the project root and change `../../` back to `./`.
